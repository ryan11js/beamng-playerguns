# Sound files

Drop .ogg files in this folder with these exact names. A weapon whose file is
missing falls back to the stock sample, so you can add them one at a time.

| File | Used for |
|---|---|
| pistol.ogg | Pistol shot |
| uzi.ogg | Uzi shot |
| thompson.ogg | Thompson shot |
| akm.ogg | AKM shot |
| sniper.ogg | Sniper shot |
| minigun.ogg | Minigun shot |
| bazooka.ogg | Bazooka launch |
| grenade.ogg | Grenade throw |
| reload.ogg | Reload (all weapons) |

Keep shot clips short (under 2 seconds), mono, 44.1 kHz. Trim leading silence
or rapid fire sounds late. Audacity exports .ogg directly.

Sources with licenses that allow redistribution in a mod:

- freesound.org, filter by the CC0 license
- sonniss.com GDC bundles, royalty free
- kenney.nl audio packs, CC0
- opengameart.org, check per-file license
- pixabay.com sound effects
